# Homing

Language for the network a user sees and the Windows configuration that connects it.

## Language

**Network name (SSID)**:
The Wi-Fi name shown by Windows and used for Homing's search, selection and target display.

**Saved profile**:
A Windows configuration containing a network's connection details. Its internal name can differ from the network name.

**Target network**:
The saved network the user has chosen for Homing to keep connected.
